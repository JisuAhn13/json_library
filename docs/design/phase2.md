# Phase 2 — 화면 흐름 설계

## 목표

사용자가 앱을 실행했을 때 어떤 순서로 화면이 전환되는지 정의한다.

---

## 전체 흐름도

```
python run.py 실행
        │
        ▼
┌─────────────────────────────┐
│  파일명 입력                 │
│  > users.json               │
│  (없으면 빈 배열로 새로 생성) │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│        메인 메뉴             │
│  [파일: users.json / 2건]   │
│  1. Create                  │
│  2. Read                    │
│  3. Update                  │
│  4. Delete                  │
│  5. 종료                    │
└─────────────┬───────────────┘
              │
     ┌────────┴────────┐
     │                 │
     ▼                 ▼
  1~4 선택           5 선택
     │                 │
     ▼                 ▼
  각 기능 화면       앱 종료
     │
     ▼
  완료 메시지 출력
     │
     ▼
  메인 메뉴로 복귀
```

---

## 각 기능 화면 흐름

### 1. Create

```
[Create] 새 레코드 추가
필드명 입력 (완료: Enter) > name
값 입력                   > 홍길동
필드명 입력 (완료: Enter) > age
값 입력                   > 30
필드명 입력 (완료: Enter) >
------------------------------------------
저장 완료:
{
  "id": 3,
  "name": "홍길동",
  "age": 30
}
```

---

### 2. Read

```
[Read]
1. 전체 목록
2. ID로 검색
3. 키-값으로 검색
선택 > 1

------------------------------------------
총 2건
[1] {"id": 1, "name": "홍길동", "age": 30}
[2] {"id": 2, "name": "김철수", "age": 25}
------------------------------------------
```

ID 검색:
```
[Read]
1. 전체 목록
2. ID로 검색
3. 키-값으로 검색
선택 > 2

검색할 ID > 1
------------------------------------------
{"id": 1, "name": "홍길동", "age": 30}
------------------------------------------
```

키-값 검색:
```
[Read]
1. 전체 목록
2. ID로 검색
3. 키-값으로 검색
선택 > 3

검색할 필드명 > city
검색할 값     > 서울
------------------------------------------
총 1건
[1] {"id": 1, "name": "홍길동", "city": "서울"}
------------------------------------------
```

---

### 3. Update

```
[Update] 레코드 수정
수정할 레코드 ID > 1

현재 데이터:
{"id": 1, "name": "홍길동", "age": 30}

수정할 필드명 > age
현재 값       : 30
새 값 입력    > 31
------------------------------------------
수정 완료:
{"id": 1, "name": "홍길동", "age": 31}
```

존재하지 않는 ID:
```
[Update] 레코드 수정
수정할 레코드 ID > 99
오류: ID 99 에 해당하는 레코드가 없습니다.
```

`id` 필드 수정 시도:
```
수정할 필드명 > id
오류: id 필드는 수정할 수 없습니다.
```

---

### 4. Delete

```
[Delete] 레코드 삭제
삭제할 레코드 ID > 2

삭제 대상:
{"id": 2, "name": "김철수", "age": 25}

정말 삭제하시겠습니까? (y/n) > y
------------------------------------------
삭제 완료: ID 2 레코드가 삭제되었습니다.
```

취소:
```
정말 삭제하시겠습니까? (y/n) > n
삭제가 취소되었습니다.
```

## 공통 규칙

| 상황 | 처리 방식 |
|---|---|
| 잘못된 메뉴 번호 | "1~5 사이의 번호를 입력하세요." 후 재입력 |
| 빈 입력(Enter만) | "값을 입력해주세요." 후 재입력 |
| 존재하지 않는 ID | "해당 ID의 레코드가 없습니다." 출력 |
| 검색 결과 없음 | "검색 결과가 없습니다." 출력 |
| 데이터 0건 | Read/Update/Delete 진입 시 "저장된 데이터가 없습니다." 출력 |
| Ctrl+C | "앱을 종료합니다." 출력 후 정상 종료 |
